Esse aqui é nosso trabalho de Org Arq.
Chamei de RISCnator porque é tipo um Akinator, só que ao invés do gênio tentar acertar o que o usuário está pensando, é o usuário que tenta acertar o que o gênio está pensando.
No caso, é um númeor de 1 a 100 que deve ser gerado aleatoriamente.
O gênio deve pedir chutes ao usuário e informando se o chute dado é maior ou menor que o número que o gênio gerou.
Ao acertar o número, o gênio deve informar todos os chutes anteriores (desempilhar essas informações).
O gênio também deve tratar números inválidos.

### ESCOLHA DE IMPLEMENTAÇÃO ###
Eu escolhi não salvar números inválidos, eu apenas não guardo eles na pilha e reinicio o loop de coleta de chutes.

### O QUE FALTA FAZER ###
O algoritmo de geração de número aleatório deve ser criado.
